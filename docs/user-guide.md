# 前端工作台使用说明（`desk.cs` Web Workbench）

本文档介绍如何在浏览器前端使用 **E-commerce Support Agent（`desk.cs`）** 智能售后工作台，涵盖界面区域说明、推荐体验路线、模拟测试数据速查及常见问题。

- **公网在线入口（魔搭创空间）**：https://modelscope.cn/studios/MamaoOvo/ecommerce-support-agent
- **本地启动访问地址**：`http://127.0.0.1:8000`（通过 `python web_server.py --mode demo` 或 `--mode live` 启动）

---

## 1. 打开页面先看顶部状态栏

页面顶部蓝灰纸面区右侧有 **4 枚运行状态徽章**，用来确认当前后端运行模式：

| 徽章显示 | 含义 |
| --- | --- |
| `MODE · LIVE` / `MODE · DEMO` | `LIVE` 表示已接入真实 DeepSeek 模型，支持任意自由自然语言对话；`DEMO` 表示零 API 费用的内置演示模式，支持常见场景与全部核心按钮演练 |
| `RAG · HYBRID RRF` / `RAG · OFF` | 是否已挂载本地 Qdrant 向量 + Okapi BM25 混合知识库检索 |
| `E2E 100 · DB 100%` | 当前版本的工程评测基线标识 |
| `TRACE · LOCAL HOOKS` / `LANGFUSE ON` | 工具调用审计模式（默认进程内 Hook 观测，配置密钥后同步上报 Langfuse） |

## 2. 前端界面三栏导览

工作台由 **左侧身份栏**、**中间实时对话台** 和 **右侧实时业务账本** 三部分组成：

### 2.1 左侧导航栏（身份绑定与演示复位）

1. **主题切换（左上角 `DARK` / `PAPER` 按钮）**：在暖纸浅色桌面与深色模式之间切换，偏好自动保存在浏览器本地。
2. **当前身份卡（`IDENTITY · 身份绑定`）**：
   - 默认以 **`GUEST（访客）`** 启动（灰点）：仅允许查询公开商品、店铺政策和公开知识库，禁止访问任何个人订单或提交写操作。
   - 点击下方模拟账号后变为 **`ALICE / BOB / CHARLIE（已验证）`**（绿点），系统自动隔离会话上下文并加载对应客户的真实 SQLite 账本。
3. **模拟账号一键切换**：
   - `alice · 6 笔多态订单`（推荐首选体验，涵盖待支付、未发货、已发货延误、已签收、已取消全状态）
   - `bob · 含拒退申诉单`（适合体验“退款被拒申诉 → 人工升级”）
   - `charlie · 待付/打款单`（适合体验待支付取消与退款打款进度查询）
   - `退出至访客（guest）`（立即回退访客态并清空所有待确认令牌）
4. **本地密码登录折叠区（`使用本地密码登录（--init-auth）`）**：当服务端开启 `STRICT_AUTH=true` 禁用一键切换时，可在此选择账号并输入 15–128 位本地密码验证登录。
5. **底部工具按钮**：
   - **`ws_...` 会话编号按钮**：点击一键复制当前 Web 会话 ID，便于排查日志。
   - **`重置演示数据库`**：将 SQLite 演示库一键恢复为初始 12 笔订单种子状态（演练完取消订单、自动退款和建工单后，可随时重置重新体验）。

> 移动端访问时，左侧栏会自动折叠为顶部精简栏，提供当前身份指示与一键 **`切至 alice`** 快捷按钮。

---

### 2.2 中间主对话台（`AGENT CONSOLE`）

1. **顶部状态条**：
   - 实时流式指示灯：`READY`（就绪）、`STREAMING`（流式思考/输出中）、`COMMITTING`（执行二次确认落库中）、`REJECTING`（取消确认中）、`OFFLINE`（后端未连通）。
   - **`RPM X LEFT`**：当前会话剩余的分钟级速率限制配额（超限触发 HTTP `429` 保护）。
   - **`CLEAR`**：清空当前屏幕聊天显示（**注意：仅清屏，不会重置服务端记忆和 SQLite 数据库**）。
2. **一键体验场景栏（上方 6 个场景胶囊）**：
   点击任意按钮即自动发送典型业务或安全测试提问：
   - `01 · 商品与取消规则`：查商品 `P104` 价格与店铺取消规则
   - `02 · 查本人全量订单`：列出当前登录账号名下所有订单及实付金额
   - `03 · 取消 A1003（两步确认）`：触发高危写操作两步确认门控
   - `04 · 跨客户查 B2001（越权拦截）`：在 `alice` 身份下试图查 `bob` 的订单，验证权限拒绝
   - `05 · Hybrid RAG 清洗禁忌`：验证向量 + BM25 混合检索与相邻原文补段
   - `06 · 延误核实 + 人工升级`：核实 `A1001` 延误物流并自动创建人工升级工单
3. **实时工具执行过程（传输条 + 工具胶囊）**：
   - Agent 正在调用工具时，对话区顶部会出现流动光点条 **`TOOL · <工具名>`** 与目标资源 ID。
   - 调用结束后，该条回复上方会沉淀出彩色 **工具胶囊**（如 `get_order(A1003) → OK 1ms` 或红色的 `get_order(B2001) → ACCESS_DENIED_OR_NOT_FOUND`），清晰展示每次推理调用了哪些工具、是否被拦截以及耗时。
4. **可视化两步二次确认门控卡片**：
   - 当你请求取消符合条件的订单时，Agent **不会在单回合内直接改库**，而是会在对话区上方弹出醒目的 **`⚠ 高危写操作 · 两步二次确认门控`** 卡片，显示确认令牌 ID（`cfm_...`）、订单号、金额、当前状态以及是否会产生原路退款单的预览。
   - 点击 **`✓ 确认取消并执行`**：正式提交 SQLite 事务取消订单（已付款未发货订单同步创建原路退款单）。
   - 点击 **`✕ 放弃取消`**：销毁待确认令牌，订单状态保持原样不变。
5. **底部命令行输入框**：
   - 提示符会随身份动态切换为 `guest@desk >>`、`alice@desk >>` 等。
   - 快捷键：**`Enter` 发送**，**`Shift + Enter` 换行**，单条消息最多 2000 字。

### 2.3 右侧实时业务账本与预算仪表盘

右侧面板直接实时读取后端 SQLite 数据库与 Hook 观测流，提供 **4 个标签页** + **底部常驻预算池**：

| 标签页 | 显示内容 | 支持的交互动作 |
| --- | --- | --- |
| **`ORDERS`** | 当前登录客户的全部 SQLite 订单（状态色点、状态标签、SKU×数量、实付金额） | 未发货/待支付订单可点 **`申请取消`**，其余订单可点 **`查详情`**（点击直接发给 Agent）；订单状态变更时会**闪烁高亮** |
| **`REFUND/TK`** | 上半区为 `refunds` 退款单表，下半区为 `tickets` 售后/人工升级工单表 | 新增退款单或工单时自动闪烁高亮；人工升级工单带有 **`HUMAN ESCALATION`** 标记与优先级 |
| **`SKU`** | 全部 6 款公开商品（访客即可查看） | 点击任意商品右侧的 **`问价`** 按钮，直接向 Agent 发起售价与规格查询 |
| **`TRACE`** | 按时间倒序记录全部 Hook 审计事件（事件类型、工具名、错误码、轮次、耗时 ms） | 实时验证工具调用链路与越权/超时/待确认等错误码 |

**底部常驻 `PROMPT CACHE & TOKEN BUDGET` 仪表条**：
- 右上角实时显示当前会话的 **Prompt Cache 缓存命中率（`HIT XX.X%`）**。
- 斜纹进度条直观区分：**绿色（缓存命中）**、**橙色（未命中全价输入）**、**蓝色（模型输出）** 与空白剩余额度（默认会话预算上限 `200k`）。

## 3. 推荐 5 分钟完整体验路线

按以下 6 步操作，可以一次性把系统的检索、鉴权、事务写库、两步确认、人工升级和缓存优化全部验完：

1. **访客态验公开知识与 Hybrid RAG（保持默认 `GUEST`）**
   - 点击 **`01 · 商品与取消规则`** 和 **`05 · Hybrid RAG 清洗禁忌`**（或切到右侧 `SKU` 点任意商品的 **`问价`**）。
   - 观察回复上方的工具胶囊（`get_product`、`get_policy`、`search_knowledge`），确认回答有据可查。
   - 再点一次 **`02 · 查本人全量订单`**，验证访客态会被明确拦截并引导先登录。
2. **切至 `alice` 验个人账本与跨客户隔离**
   - 点击左侧 **`alice · 6 笔多态订单`**，右侧 `ORDERS` 会立刻加载 `A1001`–`A1006`。
   - 点击 **`04 · 跨客户查 B2001（越权拦截）`**，确认 Agent 拒绝透露 `bob` 的订单，且工具胶囊与 `TRACE` 记录 `ACCESS_DENIED_OR_NOT_FOUND`。
3. **体验高危两步二次确认 + 自动退款落库**
   - 点击 **`03 · 取消 A1003（两步确认）`**（或直接点右侧 `ORDERS` 中 `A1003` 行的 **`申请取消`**）。
   - 先看右侧 `A1003`：状态仍是 `paid_unshipped`（**未被提前修改**）；同时对话区上方弹出二次确认卡片。
   - 点击 **`✓ 确认取消并执行`** → 观察右侧 `A1003` 闪烁变为 **`cancelled`**，再点右侧 **`REFUND/TK`**，可见已自动生成退款单 **`RF-A1003`（`¥229.00`）**。
4. **验证状态机边界（待支付 vs 已发货）**
   - 在右侧 `ORDERS` 对 **`A1002`（`pending_payment`）** 点 **`申请取消`**，可见确认卡片明确提示「待支付订单取消后**不产生退款单**」，确认后只改订单状态不建退款单。
   - 输入 `帮我取消已发货的 A1001`，观察状态机拦截并返回 `ORDER_NOT_CANCELLABLE` / 引导退货或工单。
5. **体验物流延误核实 + 人工升级 + 缓存命中观测**
   - 点击 **`06 · 延误核实 + 人工升级`**。
   - 观察 Agent 依次查单、查物流（识别 `DELIVERY_DELAY` 网点积压）并创建人工升级工单；切到右侧 **`REFUND/TK`** 可看到带 **`HUMAN ESCALATION`** 标记的新工单；看底部 **`PROMPT CACHE & TOKEN BUDGET`** 可观察到缓存命中率显著升高。
6. **切 `bob` / `charlie` 进阶演练与一键重置**
   - 切 **`bob`** 后可输入：`我的订单 B2004 退款为什么被拒了？我不认可，帮我转人工申诉`，体验拒退申诉工单。
   - 切 **`charlie`** 后可输入：`帮我查一下 C3002 的退款进度`，查看 `RF-C3002` 打款队列状态。
   - 演练结束后点击左下角 **`重置演示数据库`**，全部订单、退款与工单瞬间恢复初始状态。

## 5. 常见问题（FAQ）

- **点 `CLEAR` 和点 `重置演示数据库` 有什么区别？**
  - `CLEAR` 只清空浏览器屏幕上的历史气泡，右侧账本状态和本会话上下文不变；
  - `重置演示数据库` 会把后端 SQLite 恢复成初始 12 笔订单种子，适合重新走一遍“取消订单 → 自动建退款单”的流程。
- **为什么刷新页面后订单/聊天记录变了？**
  - 每次刷新页面都会创建一个新的隔离 Web 会话（新的 `ws_...` ID，默认回到 `GUEST` 访客态），但 SQLite 演示库中的订单变更会持久化保留，直到点击 **`重置演示数据库`** 或容器重启。
- **为什么发消息太快会提示限流（HTTP `429`）？**
  - 后端内置滑动窗口限流（默认每分钟 20–30 次，右上角 `RPM X LEFT` 可见剩余额度），稍等窗口滑动恢复后即可继续发送。
- **`DEMO` 模式和 `LIVE` 模式体验上有什么差异？**
  - `DEMO` 模式使用内置脚本化演示模型（0 费用），能完整跑通 6 个快捷场景、商品问价、订单查询、两步取消确认、跨客户拦截和人工建单，但对任意开放式自由提问的泛化能力有限；
  - `LIVE` 模式接入真实 DeepSeek 模型，支持任意多轮复杂追问、结合 Hybrid RAG 深度推理以及实时展示真实 Token 消耗与 Prompt Cache 命中率。
- **二次确认卡片除了点按钮，能在对话框里打字确认吗？**
  - 可以。在 `LIVE` 模式下直接回复“确认取消”也能完成两步确认；前端可视化门控卡片则是把确认令牌直接提交给后端鉴权接口，更直观且防止模型误判。
